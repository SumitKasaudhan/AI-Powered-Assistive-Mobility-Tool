# 🚀 VisionMate AI-Powered-Assistive-Mobility-Tool-for-Visually-Impaired

## 📌 Project Summary

**VisionMate** is a real-time AI-based assistive system designed to enhance environmental awareness for visually impaired individuals through intelligent video analysis and audio feedback.

The system integrates advanced computer vision and deep learning models such as YOLOv8 and BLIP to deliver contextual, real-time insights from video input.

> ⚡ Built as part of an industry-aligned internship under Infosys Springboard, focusing on real-world AI applications.

## 🎯 Key Highlights

* ✅ Developed a **real-time video processing pipeline** using Python and AI models
* ✅ Implemented **frame-by-frame object detection** to ensure zero data loss
* ✅ Integrated **multimodal AI (vision + language + audio)**
* ✅ Built an **interactive web application** using Streamlit
* ✅ Designed **assistive audio feedback system** using gTTS
* ✅ Applied **secure authentication** with bcrypt
* ✅ Optimized system for **low latency and high accuracy**
